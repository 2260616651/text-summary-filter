# 示例文档：新能源电池回收行业观察

## 第一章 行业背景
全球动力电池装机量在 2020 年后进入爆发期。据行业测算，首批规模化装机的动力电池将在 2025 至 2028 年迎来退役高峰。退役不等于报废，其中仍有大量可梯次利用的电芯与高价值金属材料。

动力电池回收分为梯次利用和再生利用两条路径。梯次利用把衰减至 80% 容量以下的电池用于储能、低速车等场景；再生利用则通过湿法或火法工艺提取锂、钴、镍等金属。

## 第二章 技术路线
湿法回收目前是主流，金属回收率高，但废水处理成本高。火法回收工艺简单，但能耗大、锂回收率低。近年出现了直接修复再生技术，试图跳过冶炼环节，直接修复正极材料晶体结构。

直接修复再生技术仍处于中试阶段，规模化经济性尚未验证。业内普遍认为，2030 年前湿法仍将占据主导，但直接修复是值得关注的颠覆性方向。

## 第三章 政策与市场
各国相继出台生产者责任延伸制度，要求车企与电池厂承担回收义务。中国市场通过白名单管理规范回收主体，目前合规产能远大于实际退役量，行业处于产能出清前期。

回收金属的价格随上游锂价剧烈波动。2023 年锂价高位回落，一度挤压回收企业利润；但长期看，资源自主可控的逻辑没有改变，回收的战略价值持续提升。

## 第四章 总结
新能源电池回收是连接"生产—使用—再生"的关键闭环。技术路线上湿法主导、直接修复蓄势；政策上责任延伸与白名单并行；市场上短期承压、长期向好。能否跑通经济性与合规性，将决定这一赛道最终的赢家。

# 附：本示例怎么用（入门）

`sample.md` 是 doc-extract-filter 的**短样例源文档**，用于确认等宽切块、`⟦OVERLAP⟧` 重叠标记与自然边界吸附长什么样。
真正的完整流程见 `SKILL.md` 的「0. 一句话启动」与 `references/quickstart.md`。

```bash
# 1) 只看体量分析（不切）
python scripts/split_document.py --analyze examples/sample.md

# 2) 切块看重叠标记（**演示用小尺寸需同时压 --min-chunk**：默认硬下限 40000 会把 200 抬到 40000，
#    本样例只切出 1 块、看不到重叠。真实文档请按自生专注力推导块大小，不要照抄这组小数字。）
python scripts/split_document.py --chunk-size 200 --min-chunk 100 --overlap 0.25 --out out examples/sample.md
# 产物：out/chunks.json（块号/字符数/overlap_source/overlap_char_count）+ out/chunk_001.txt …
# 实测：6 块；chunk_002.txt 开头可见 ⟦OVERLAP 来自块0尾部·重复区⟧ … ⟦OVERLAP 结束⟧

# 3) 验证结构保护：围栏/表格/标题不会被从中间切开（默认开启，超上限时「宁可超、不切断行」）
python scripts/split_document.py --chunk-size 200 --min-chunk 100 --prefer-headings --out out2 examples/sample.md
# --no-preserve-structure 可退回旧行为；--no-mark 去掉 ⟦OVERLAP⟧ 字样但保留重叠正文
```

观察点：
- 切点只落在段落/句子/标题等自然边界，**绝不切断行**；
- 后一块开头带 `⟦OVERLAP 来自块N尾部·重复区⟧ … ⟦OVERLAP 结束⟧`，标记内文本属该块自身内容；
- 短文档（< 4 万字符）在标准总结主流程可直接一次性总结、不必切块（见 SKILL.md「何时使用·短文档短路」）。

> 本样例仅演示切分，**不是**「条目合并 + 内容筛选」流水线的输入；
> 后者请用 `scripts/run_pipeline.py`（或先跑 `scripts/route.py` 做意图路由）。
